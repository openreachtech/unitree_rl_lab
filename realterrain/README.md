# realterrain — 実地形歩行ポリシー開発

**方針**: 横浜国大で実際に使う「敷居（しきい）のある段差ブロック」地形を Isaac Sim に忠実再現し、その上で Go2 を歩かせるポリシーを開発する。**blind（外界センサなし）と height-scan（地形を“見る”）の両方**を作って比較する。
